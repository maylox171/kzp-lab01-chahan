| Поле | Тип після читання | Правило |
|------|-------------------|---------|
| animal, species, owner, diagnosis | str | `strip()`, непорожнє |
| date | datetime.date | ISO `YYYY-MM-DD` |
| cost | float | число, скінченне, ≥ 0 |

Контрольні випадки: 6 записів; дубльовані власники (Іваненко Олена, Коваль Андрій); граничне значення
`cost = 1000.00` (Джек) не проходить відбір `> 1000.0`; текст із комою й подвоєними лапками (Рекс);
порожній результат відбору — `--threshold 5000`.
**Поріг:** `threshold = 1000.0`. **Порожній вхід:** файл лише із заголовком (`data/empty.csv`) дає
порожній список і звіт із нулями; повністю порожній файл без заголовка — `DataError`.

## 5. Перетворення даних

- перетворюються три поля: `cost` → float, `date` → date, текстові поля нормалізуються `strip()`;
- список: `records: list[dict[str, object]]`, `select_expensive` — list comprehension;
- словник: `count_by_species` — dict comprehension із відсортованими ключами;
- множина: `unique_owners` — set comprehension;
- генераторні вирази в `average_cost`, `make_summary`.

## 6. Функції

```python
def make_summary(records, *metrics, threshold=THRESHOLD, **labels) -> dict[str, object]: ...


make_summary(records, "cost", cost="Сума дорогих")  # сума cost відібраних записів = 3700.0
```

`metrics` усередині — кортеж, `labels` — словник; типове значення `threshold=1000.0` незмінне.
Невідома метрика → `ValueError`; порожній відбір дає суму `0`.

## 7. Алгоритм аналізу

1. Відбір `cost > threshold`, сортування за вартістю (спадання), потім за кличкою.
2. Словник: кількість візитів за `species` (ключі відсортовані).
3. Множина власників (у звіті — відсортована).
4. Звіт: середня вартість (0.0 для порожнього входу) і найдорожчий візит (`max(..., default=None)`).

## 8. Обробка помилок

| Випадок | Повідомлення `DataError` | `__cause__` |
|---------|--------------------------|-------------|
| `дорого` у cost | Рядок 3: поле cost має бути числом | ValueError |
| cost −150 | Рядок N: cost не може бути від'ємним | — |
| немає стовпця | Відсутні стовпці CSV: cost | — |
| мало значень | Рядок 2: відсутнє значення поля … | — |
| порожній owner | Рядок N: поле owner порожнє | — |
| хибна дата | Рядок N: поле date має формат YYYY-MM-DD | ValueError |
| файл відсутній | Не вдалося прочитати файл | OSError |

Голого `except` немає. CLI: успіх — код **0**; `DataError` — повідомлення в stderr (UTF-8) і код **2**;
помилка аргументів argparse — код 2.
